END-TO-END ML PIPELINE

How StockAI Works

Stock Prediction AI follows a structured pipeline that transforms market data into a machine learning prediction. The process begins with historical stock information, continues through data preparation and feature engineering, then passes the prepared inputs into the trained Random Forest Regression model. Finally, the prediction is returned through the Flask API and displayed on the website.

STEP-BY-STEP PROCESS

Complete StockAI Workflow

Each stage has a specific responsibility in the complete stock prediction process.

01
STEP 01

Market Data Collection

📡

The system begins by retrieving historical stock market information. The dataset contains daily values that describe the stock's market activity. These raw values provide the foundation for the machine learning process.

Open High Low Close Volume
02
🧹
STEP 02

Data Preparation

After collecting the market information, the data is prepared before it is supplied to the machine learning model. Invalid or unusable values are handled and the dataset is arranged into the required structure.

Data Cleaning Numeric Conversion Missing Values Data Structure
03
STEP 03

Feature Engineering

⚙️

Raw market information is converted into additional features that describe recent stock behavior. These features become the input variables used by the trained regression model.

Previous Close Daily Return MA-5 MA-10 Price Range
04
🧠
STEP 04

Machine Learning Model

The prepared features are given to the trained Random Forest Regression model. During training, the model learns relationships between the input features and the next closing price.

Random Forest Regression 200 Trees Trained Model
05
STEP 05

Price Prediction

🔮

Once the latest feature values are prepared, they are passed to the trained model. The model generates a numerical prediction representing the estimated next closing price.

Latest Features Model Input Predicted Price
06
🎯
STEP 06

Signal Generation

The predicted price is compared with the current market price. The percentage difference is then used to generate a simplified BUY, SELL or HOLD signal for the interface.

BUY SELL HOLD
07
STEP 07

Flask API Response

🔌

The Flask backend packages the model output and market information into a response. The frontend requests this information through the prediction API and receives the result.

Flask REST API JSON Backend
08
🖥️
STEP 08

Display Final Result

The website displays the current market price, daily change, high, low, predicted price and generated signal in a clear and user-friendly interface.

Live Price Prediction Change Signal

SYSTEM COMPONENTS

How The Main Components Work Together

StockAI combines frontend, backend, data processing and machine learning components into a single end-to-end application.

🌐

Frontend

HTML, CSS and JavaScript provide the user interface. Users can enter a stock symbol and view the returned prediction results.

🔥

Flask Backend

Flask receives prediction requests, retrieves market information, prepares model features and calls the trained machine learning model.

📡

Market Data

Market data provides the price and volume information used by the backend for current analysis and prediction.

🧮

Data Processing

Pandas and Python logic are used to arrange, convert and prepare the market dataset before generating model input.

🌲

Machine Learning

The saved Random Forest Regression model acts as the main prediction engine and estimates the next closing price.

🎯

Result Engine

The backend compares current and predicted prices and converts the difference into a BUY, SELL or HOLD signal.

FRONTEND ↔ BACKEND

Prediction API Connection

The browser communicates with the Flask server through the prediction endpoint to receive machine learning results.

🔌 How The API Works

When a user enters a stock symbol and clicks Predict Now, the website sends a request to the Flask prediction endpoint. The backend retrieves market information, prepares the required features and passes them to the trained model. The response is then returned to the browser and displayed in the prediction interface.

✓ User enters stock symbol
✓ Frontend sends API request
✓ Flask processes the request
✓ Machine learning model predicts
✓ JSON result returns to browser
