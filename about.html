Understanding Stock Prediction AI

Stock Prediction AI is a Machine Learning based web application designed to analyze historical stock market data and estimate future stock prices. The project combines Python, Flask, Yahoo Finance data and Random Forest Regression into one intelligent system.

PROJECT OVERVIEW

What This Project Does

The system processes historical market information, creates useful machine learning features and uses a trained model to estimate the next stock price.

📥

Data Collection

The application collects historical stock information including Open, High, Low, Close and Volume values from market data.

⚙️

Feature Engineering

Additional features such as Previous Close, Daily Return, MA-5, MA-10 and Price Range are calculated from the market data.

🌲

Machine Learning

A Random Forest Regression model learns relationships between historical features and the next stock closing price.

🔌

Flask Backend

Flask loads the trained stock_model.pkl file and provides prediction results through the /api/predict endpoint.

🌐

Web Interface

The frontend allows a user to enter a stock symbol and view current market information together with the model prediction.

🎯

Signal Generation

The system compares predicted and current prices and generates a BUY, SELL or HOLD signal based on the percentage difference.

PROJECT OBJECTIVES

01
