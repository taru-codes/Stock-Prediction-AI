The Intelligence Behind StockAI

StockAI uses a trained Random Forest Regression model as the main machine learning engine. The model learns relationships between historical stock market features and the next closing price, allowing the backend to generate a prediction for the selected stock data.

RANDOM FOREST
PRIMARY MODEL

Random Forest Regression

Random Forest Regression is the main model used by this project to estimate the next stock closing price.

🌲

Random Forest Regressor

Random Forest is an ensemble machine learning algorithm that combines many decision trees. Each tree learns patterns from training data, and their outputs are combined to produce a regression result.

Supervised Learning Regression Ensemble Model Decision Trees Python
MODEL CONFIGURATION
Number of Trees

The project trains the Random Forest using 200 decision trees.

Maximum Depth

Maximum tree depth is set to 12 to control the complexity of individual trees.

Minimum Split

A minimum of 5 samples is required for a node to be split.

Random State

Random state 42 is used so that the training process can be reproduced.

Target

The target variable is the next trading day's closing price.

MODEL ADVANTAGES

Why Random Forest?

The project uses Random Forest because the ensemble structure can represent complex relationships between multiple input features.

🌲

Multiple Trees

Instead of depending on a single decision tree, Random Forest combines many trees to generate a more stable ensemble prediction.

🧠

Pattern Learning

The model learns relationships between market variables and the target price during training.

📊

Multiple Inputs

The model can use Open, High, Low, Close, Volume and calculated indicators together.

⚡

Fast Inference

After training, the saved model can be loaded by Flask and used to generate predictions through the API.

🔄

Reusable Model

The trained model is saved as stock_model.pkl and can be loaded whenever the application receives a prediction request.

🎯

Regression Output

The model produces a numerical prediction, which in this project represents the expected next closing price.

MODEL EVALUATION

Measuring Model Performance

Model performance can be evaluated by comparing predicted values with the actual target values.

📏

MAE

Mean Absolute Error represents the average absolute difference between actual and predicted values. Lower error indicates smaller average prediction differences.

🧮

RMSE

Root Mean Square Error measures prediction error while giving greater influence to larger errors.

📐

R² Score

The R² score indicates how much of the variation in the target values is explained by the regression model.
