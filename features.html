MODEL EVALUATION

Understanding Prediction Quality

Machine learning performance can be studied using evaluation metrics that compare actual values with predicted values.

📏

MAE

Mean Absolute Error measures the average absolute difference between actual and predicted values.

🧮

RMSE

Root Mean Square Error gives greater importance to larger prediction errors.

📐

R² Score

R² indicates how well the model explains the variation in the target data.

🎯

Target

The regression model is trained to predict the next stock closing price.
